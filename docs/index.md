# ColmenaOS Documentation Index

## Overview
This directory consolidates the working objectives, roadmap, and implementation references for ColmenaOS. Each document captures an approved decision; exploratory notes stay in `context/`.

## Quick Links

- [Roadmap](./20-roadmap.md) — phased delivery plan mapped to objectives.

2. Check the **Roadmap** for sequencing and ownership.
3. Dive into **Implementation Notes** for service-level details.

For in-progress research or brainstorming, continue to use the `context/` folder and promote stable decisions here when they solidify.
